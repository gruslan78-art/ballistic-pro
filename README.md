# BALLISTIC PRO PWA

Мобильная PWA-версия. Содержит каталог оборудования, локальный журнал, экран независимых измерений, электронный уровень (если браузер разрешает датчики) и график вручную внесённых наблюдений.

## Публикация на GitHub Pages
1. Загрузите все файлы и папки из архива в корень репозитория `gruslan78-art/ballistic-pro`.
2. В GitHub откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Branch: `main`, Folder: `/ (root)`, затем Save.
5. Через несколько минут сайт будет доступен по адресу `https://gruslan78-art.github.io/ballistic-pro/`.

## Установка на iPhone
Откройте опубликованный адрес в Safari → Поделиться → На экран «Домой».

Данные журнала и оборудования хранятся локально в браузере конкретного устройства. Для резервного копирования пока не предусмотрена синхронизация.

Приложение не рассчитывает оружейные поправки, настройки барабанов, траектории или точки попадания. Измерительный раздел предназначен для независимых измерений и наблюдений.
